# Disasters-Philippines-
# Predicting Post-Disaster Poverty Trajectories in the Philippines

This repository contains the full implementation of my individual data science project on the link between **natural disasters** and **poverty dynamics** in the Philippines. The main research question is: to what extent can we predict post-disaster poverty trajectories based on disaster intensity and socioeconomic conditions?

The project focuses on:

- 1.Which disaster features most influence poverty change?
2.Does disaster intensity matter more than pre-disaster vulnerability?
3.Are coastal regions more sensitive than inland ones?

The analysis combines data cleaning, panel construction and simple machine learning models (Linear Regression, Random Forest and Gradient Boosting).

## 2. Data Sources

The project uses the following data:

- **EM-DAT – International Disaster Database**  
  Disaster events affecting the Philippines (2004–2024): type, location, deaths, affected, damages.

- **Philippines national poverty statistics**  
  National poverty rates over time.

- **World Bank – World Development Indicators (WDI)**  
  GDP growth and unemployment rate for the Philippines.

- **Regional poverty statistics (women & children)**  
  Regional poverty incidence for women and children in 2018, 2021 and 2023, including additional tables obtained via CEDIF.


All datasets are harmonised by year and by region during the cleaning stage.
